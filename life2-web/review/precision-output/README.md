# 정밀진단 출력 수정안 — 운영 미적용

기준 운영 main: a0fa5d19611cc630127455e3868b3bc9a5f1fc06.
현재 운영 index.html을 수정하지 않은 별도 검토안이다.

## 수정 내용
- 설문 후 리포트가 다시 그려져도 fullReportWrap 안에 PDF 저장/인쇄 버튼을 유지한다.
- 기존 premium + survey 완료 조건을 확인하고, 클릭 시 다시 확인한다.
- 기존 printReport 함수를 호출한다. 새 인쇄 엔진이나 금융 계산을 만들지 않는다.
- 현재 생활비 시나리오의 설명을 실제 입력 변경과 동일 엔진 재계산으로 제한한다. 목표 생활비는 그대로라는 사실만 설명하고, 소진 변화 없음/개선 기간을 임의 확정하지 않는다.
- 재렌더, 숨긴 리포트, 미해금, 짧은 설문, 저장 접근 오류, 언어 변경을 테스트한다.

## 상태와 적용 경계
proposal.js는 현재 어떤 운영 페이지에서도 로드하지 않는다. integration.patch 역시 적용하지 않았다.
로컬 Node 계약 테스트 5개 통과, git apply --check 통과, 기존 index.html 무변경 확인.
실제 인쇄 미리보기/PDF 파일의 페이지·잘림·빈 페이지 검증은 아직 미완료이다.

명시적인 운영 수정·배포 승인 후에만 integration.patch를 적용하고, 동봉 proposal.js를 배포 경로에 포함한다. main 병합은 별도 승인 필요.
기존 채점 엔진과 Google Master DB, Supabase Identity/FACT를 변경하지 않는다.
