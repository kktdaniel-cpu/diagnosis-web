# LIFE 2.0 질문·보기 및 화면 검토표 v1

검토일: 2026-10-13. 질문/보기와 디자인을 별도로 검토합니다. 이 문서는 수정 제안이며 운영 반영 승인·진단 타당성 PASS가 아닙니다.

근거: 운영 /questions API의48개 항목, 개발 소득공백12문항, Awareness12문항, 회원 검토7그룹 및 현재 화면 코드. API 전체 목록은 조건부·보관용 항목도 포함하므로 실제 노출 수는 다를 수 있습니다. 공식 제도·통계 문구는 이번 검토에서 사실 검증하지 않았습니다. 실제 모바일·PDF 검증도 별도입니다.

## 먼저 검토할 사항

- 운영: Q12/Q29 없음·모름 혼합, Q26 잔액×3% 안내, Q39 비밀번호 공유 표현. 엔진 입력 의미와 함께 검토하고 운영은 별도 승인 후 변경.
- 파일럿: G01 가구 정의, G04 생활비 시점, G05 대출0 분기, G08 대표 연금 범위, G09 계획/확인 구분.
- 회원 화면: 저장된 초안에서 신규 초안 저장 동의를 다시 노출하고 있어 덮어쓰기/새 초안 혼동 가능. 재검토 저장과 새 초안 시작을 분리 제안.

## Awareness12와 회원 확인7그룹

Awareness는 준비를 확인했는지 묻는 상태 점검, 소득공백은 월 시점·금액을 받는 상세 초안입니다. 동일 질문을 무조건 삭제하지 말고 상태 점검→확인 Action 관계를 유지합니다. 나이대 사전 선택과 출생연도/월 시점의 목적은 구분합니다.

## 검토와 반영 절차

1. 대표님 문항 의미 검토: 유지/수정/삭제/추가 확인에 의견 기록.
2. 보기나 단위 변경은 서버계약·분기·저장 FACT 영향까지 함께 확인.
3. 승인된 범위만 개발용에 반영 → 의미 있는 테스트 → 실제 화면 확인.
4. 운영 정밀진단 변경은 기존 엔진 회귀와 별도 운영 승인 후.
5. 대상 사용자에게 소리내어 답하도록 요청하고, 이해 못한 표현/오답/이탈 위치 기록. 사용자 테스트 전에는 사용성 PASS로 표기하지 않음.
