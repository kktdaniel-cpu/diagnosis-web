### Q6 · 본인 국민연금 총 가입기간은? (앞으로 낼 기간 포함 - 60세까지)

안내: 노령연금 개시 연령: 1969년생 이후 만 65세 (1953~68년생은 61~64세). 10년 이상 가입해야 수급요건을 충족합니다. 10년이 안 되면 노령연금 대신 반환일시금을 받으며, 60세 이후 임의계속가입으로 기간을 채울 수 있습니다(뒤에서 여쭙니다).
